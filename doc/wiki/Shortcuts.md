# Shortcuts

Every key the desk has, and how a PC keyboard becomes a Spectrum's. `Help → Keys` shows the first list
inside the emulator, read from the menus as they stand.

## The desk

These answer when no machine has the keyboard: on an empty desk, or while a window you type into, such as
the game browser, is in front. While a machine has the focus the keyboard is the Spectrum's, Ctrl and Alt
included, and these do nothing. Every one of them is also in a menu or on a machine's bar.

| Keys | What |
|---|---|
| Ctrl+N | a new machine |
| Ctrl+O | open a file |
| Ctrl+1 … Ctrl+0 | the ten files opened last, under `File → Recent Files` |
| Ctrl+S / Ctrl+L | save and load the state of the machine in front |
| Ctrl+T | flat out, and back |
| Ctrl+Space | pause |
| Ctrl+M | mute |
| Ctrl+Shift+P | *What do you want to do?*: find anything by name |
| Ctrl+W / Ctrl+Shift+W | close the window in front, or all of them |
| Alt+1 / Alt+2 | cascade, or tile |
| Esc | leave full screen |
| Ctrl+Q | quit; everything comes back next time |

## A Spectrum's keys on a PC

While a machine has the focus, your keyboard is its keyboard.

| On your keyboard | On the Spectrum |
|---|---|
| Shift | CAPS SHIFT |
| Ctrl or Alt | SYMBOL SHIFT |
| Tab | extended mode |
| the arrow keys | the Spectrum's arrows, on 5 to 8 |
| Backspace | DELETE |
| Esc | EDIT |
| Caps Lock | CAPS LOCK |
| `"` `,` `.` `;` `:` `+` `-` `=` `*` `/` `<` `>` `?` `!` `$` `%` `&` `(` `)` `_` `@` `#` `'` `^` | the same sign, wherever the Spectrum keeps it |

So `PRINT "HELLO"` is typed as it reads: `P`, then `"HELLO"`. And a keyword that lives in extended mode, such
as `OUT`, is Tab and then Ctrl with its key.

`Emulator → Equipment → Keyboard` shows which of the Spectrum's keys are down at any moment.
→ [Sound and controls](Sound-and-controls)
