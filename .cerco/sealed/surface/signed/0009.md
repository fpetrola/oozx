## Grows

- machine/core
  - `com.fpetrola.oozx.config.RomFiles.Consent#bring(RomFiles, List<String>): boolean`
  - `com.fpetrola.oozx.speccy.machine.Roms#readyFor(Object): boolean`

## Need

A board plugged in from the desk (DeviceFrame in machine/devices/kit) has to bring the ROMs it is made with before
it is switched on, as a machine already did; the only code able to ask the person and fetch them was a static on a
dialog in machine/app, which kit cannot see. Roms#readyFor lets anything holding the machine's ROMs ask whether a
machine or board can be started, and Consent#bring lets the window decide how the bringing is watched.

## Considered

- com.fpetrola.oozx.config.RomFiles.Consent#toDownload(String, String): boolean — answers one ROM at a time from the
  thread that fetches, so it cannot open one window for everything a board is missing and wait on it from the
  window's own thread; asking per file is how the emulator hung before.
- com.fpetrola.oozx.speccy.machine.Roms#of(Peripheral, int, int): byte[] — is asked while the board is being built on
  the emulator's loop, where nothing may stop to ask a person or wait on the network, so it can only fail.

statics and progress callbacks that no plugin calls.
