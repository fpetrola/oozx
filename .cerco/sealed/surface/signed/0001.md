## Need

A peripheral window has words to put into the machine: the Currah µSpeech speaks what a BASIC line assigns
to s$, and typing that line by hand means Symbol Shift for every quote and equals sign. The window needs to
hand a whole text to the machine's keyboard and have each character pressed and let go in turn, held long
enough for the ROM's scan, with the shifts it needs. The host keyboard also needs to ask which key types a
character, which it used to answer with its own table of 92 entries repeating the keys' own codes.

## Considered

- `com.fpetrola.oozx.speccy.modules.keyboard.KeyLayout#pressed(Input.InputKey): void` says one key went down
  as the layout sees it; it neither lets go nor paces anything, and it does not know which key a character
  is, so every caller with a text would rewrite the timing and the character table on its own.
