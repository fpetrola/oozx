Tint.apply switched over Shade to know how each shade pushes the colours, and isTransparent compared the shade with
NONE; ShadowMask did the same with Pattern (== NONE to know whether it is drawn, == SLOT_MASK to know whether rows are
staggered). The enums were names only: everything a shade or a pattern means lived in the effect that used it, written
as a decision per constant. A shade is so much brightness plus so much of each channel itself, which is data each
constant can hold; a pattern knows whether it is drawn and how it shifts a row. With that on the constants the effects
ask them instead of deciding over them.

model: variation-as-data
